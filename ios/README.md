# iOS Recipe Extractor Components

This folder contains Swift and JavaScript snippets for a SwiftUI iOS app and Share Extension that extracts Recipe JSON-LD from Safari and formats it for Notes.

## Files
- `RecipeModel.swift`: Codable models and extractor helpers that normalize JSON-LD recipe content and produce Markdown output.
- `RecipeExtractor.js`: JavaScript injected into Safari to locate `<script type="application/ld+json">` blocks and post recipe JSON via a message handler.
- `ShareViewController.swift`: Share extension entry point using `SLComposeServiceViewController` plus a SwiftUI sheet for preview/copy actions.
- `ContentView.swift`: Main app view for manually testing URL inputs and storing extracted recipes.
- `ShareExtensionInfo.plist`: Example extension plist configuration using `NSExtensionActivationSupportsWebPageWithMaxCount`.

## Share Extension Info.plist keys
```xml
<key>NSExtension</key>
<dict>
    <key>NSExtensionPointIdentifier</key>
    <string>com.apple.share-services</string>
    <key>NSExtensionPrincipalClass</key>
    <string>ShareViewController</string>
    <key>NSExtensionAttributes</key>
    <dict>
        <key>NSExtensionActivationRule</key>
        <dict>
            <key>NSExtensionActivationSupportsWebPageWithMaxCount</key>
            <integer>1</integer>
        </dict>
    </dict>
</dict>
```

Set `NSExtensionPrincipalClass` to the fully qualified name generated by your target (e.g., `$(PRODUCT_MODULE_NAME).ShareViewController`).
